API Reference

Complete API documentation for the Performance Problem Simulator. All endpoints are prefixed with /api.

⚠️ Warning: Simulation endpoints intentionally create performance problems. Only use in controlled educational environments.

Health & Metrics

GET /api/health

Check application health status.

Response:

{ "status": "healthy", "timestamp": "2024-01-01T00:00:00Z" }
GET /api/metrics

Get current system and process metrics.

Response:

{
  "system": {
    "cpu_percent": 25.5,
    "memory_percent": 60.2,
    "memory_available_mb": 8192
  },
  "process": {
    "cpu_percent": 5.2,
    "memory_mb": 128.5,
    "threads": 8
  }
}

CPU Stress Simulation

Create CPU load using multiprocessing workers performing floating-point calculations.

POST /api/cpu/start

Start CPU stress simulation.

Request Body:

{
  "duration_seconds": 30,  // Optional, null for indefinite
  "intensity": 5,          // 1-10, default 5
  "workers": 2             // 1-16, default CPU count
}

Response:

{
  "simulation_id": "uuid",
  "workers": 2,
  "message": "CPU stress started"
}
POST /api/cpu/stop

Stop a specific CPU simulation by ID.

Request Body:

{ "simulation_id": "uuid" }
POST /api/cpu/stop-all

Stop all running CPU simulations.

Memory Pressure Simulation

Allocate and release memory blocks to simulate memory pressure.

POST /api/memory/allocate

Allocate a memory block.

Request Body:

{ "size_mb": 100 }  // 1-2048 MB

Response:

{
  "block_id": "uuid",
  "size_mb": 100,
  "message": "Memory allocated"
}
POST /api/memory/release

Release a specific memory block.

{ "block_id": "uuid" }
POST /api/memory/release-all

Release all allocated memory blocks.

GET /api/memory/status

Get current memory allocation status.

Blocking Simulation

Simulate synchronous (thread pool) and asynchronous (event loop) blocking.

POST /api/blocking/sync

Block thread pool workers with synchronous sleep.

{
  "duration_seconds": 5,  // 0-300
  "count": 1              // 1-100
}
POST /api/blocking/async

Block event loop with synchronous sleep (anti-pattern demo).

{
  "duration_seconds": 5,
  "chunk_ms": 100  // Optional: yield between chunks
}

Slow Request Simulation

Generate artificially delayed responses.

GET /api/slow?delay_seconds=5

Return response after specified delay (0-300 seconds).

POST /api/slow/start

Start periodic slow request generator.

{
  "interval_seconds": 1,
  "max_requests": 10,
  "delay_seconds": 5
}
POST /api/slow/stop

Stop the slow request generator.

Crash Simulation

⚠️ Danger: These endpoints will terminate the application!
GET /api/crash/types

List available crash types with diagnostic information.

POST /api/crash

Trigger application crash (requires confirmation).

{
  "crash_type": "exception",  // exception, stackoverflow, oom, sigabrt
  "confirmed": true           // Must be true
}

Administration

POST /api/failed-requests

Generate HTTP 500 error log entries.

{ "count": 10 }  // 1-1000
POST /api/admin/reset

Stop all simulations and release all resources.

GET /api/admin/stats

Get detailed application statistics.

WebSocket

WS /ws/metrics

Real-time metrics stream. Receives JSON messages every 500ms with system/process metrics.
