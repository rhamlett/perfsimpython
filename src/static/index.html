🎮 Simulation Controls

🔥 CPU Stress ⓘ

Spawns worker threads that compete with the event loop for CPU time. Due to Python's GIL, total CPU usage maxes out around 50-60%, but request latency increases significantly.

📊 Memory Pressure ⓘ

Allocates memory blocks filled with random data. Multiple allocations stack - mimics gradual memory leak.

🧵 Async Blocking ⓘ

Blocks async operations using sync-over-async anti-pattern to simulate event loop starvation. Server becomes unresponsive to new requests.

⏱️ Duration Note: Python's asyncio runs on a single thread by default. Even a few blocking operations can cause significant impact.

🐌 Slow Requests ⓘ

Generates requests that intentionally take a long time. Ideal for profiler diagnosis in Azure.

⚠️ Note: Requests exceeding 30 seconds total time are flagged as critical

❌ Failed Requests ⓘ

Generates HTTP 5xx errors for testing error monitoring. Creates authentic server errors.

📊 Where to see: Azure Portal → App Insights → Failures blade

💥 Application Crash ⓘ

Triggers a fatal crash to test crash monitoring and diagnostics. Choose from various crash types.

⚠️ This will TERMINATE the app!
